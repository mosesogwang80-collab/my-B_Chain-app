6. Entity-Relationship Diagram (ERD)

The database structure and how tables connect.

erDiagram
    USER ||--o{ WASTE_REQUEST : "1:N (Reports/Collects)"
    USER ||--o{ MESSAGE : "1:N (Sends/Receives)"
    WASTE_REQUEST ||--|| SYSTEM_SETTING : "1:1 (Rates)"
    
    USER {
        string username PK
        string role
    }
    WASTE_REQUEST {
        string id PK
        string reporter_username FK
        string collector_username FK
        string status
    }
    MESSAGE {
        int id PK
        string sender FK
        string recipient FK
    }
    SYSTEM_SETTING {
        string key PK
        string value
    }
